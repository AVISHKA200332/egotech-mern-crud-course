What React Does in This Project

React is the part of the app that users interact with. It renders the list of students, shows the form for adding or editing data, and updates the screen whenever state changes. In this course, React is the layer that sits in front of your Express API.

What the user sees
Buttons, forms, tables, alerts, and navigation.
What React manages
Component state, loading indicators, and UI updates after API calls.

Create the Frontend Project

Use Vite to bootstrap the React app. It keeps the setup small, fast, and modern.

Frontend setupCLI
npm create vite@latest frontend -- --template react

Components and Props

Break the UI into small pieces. Each component should have one clear job. The parent component decides what data to show, and child components receive that data through props.

StudentCard.jsxJSX
export default function StudentCard({ student, onEdit, onDelete }) {
	return (
		<div className="card shadow-sm mb-3">
			<div className="card-body d-flex justify-content-between align-items-center">
				<div>
					<h5 className="mb-1">{student.name}</h5>
					<p className="text-muted mb-0 small">{student.email} · {student.course}</p>
				</div>
				<div className="d-flex gap-2">
					<button className="btn btn-sm btn-outline-primary" onClick={() => onEdit(student)}>Edit</button>
					<button className="btn btn-sm btn-outline-danger" onClick={() => onDelete(student._id)}>Delete</button>
				</div>
			</div>
		</div>
	);
}

useState Example

The state object stores the current form values. When the user types, React updates the state and re-renders the form instantly.

StudentForm.jsxJSX
import { useState } from 'react';

const initialForm = { name: '', email: '', age: '', course: 'IT' };

export default function StudentForm({ onSave }) {
	const [formData, setFormData] = useState(initialForm);

	const handleChange = (event) => {
		setFormData({ ...formData, [event.target.name]: event.target.value });
	};

	return null;
}

Controlled Forms and Validation

In a controlled form, every input value comes from React state. This makes validation and submission much easier to reason about.

Form submit exampleJSX
const handleSubmit = async (event) => {
	event.preventDefault();

	if (!formData.name || !formData.email) {
		setMessage('Please fill in all required fields.');
		return;
	}

	await onSave(formData);
	setFormData(initialForm);
};
Keep validation messages short and specific. Beginners should know exactly what field needs attention and why the value is invalid.
