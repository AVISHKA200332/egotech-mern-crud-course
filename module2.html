Step 1

Install Node.js

What is Node.js?

Node.js lets you run JavaScript on your computer (not just in a browser). It also comes with npm — a tool that lets you install packages (ready-made code written by other developers).

1
Go to nodejs.org

Visit nodejs.org and download the LTS version (Long Term Support). LTS means it's the most stable version.

2
Run the installer

Double-click the downloaded file and click "Next" through all steps. Keep all default settings.

3
Verify installation

Open your terminal (Command Prompt on Windows, Terminal on Mac) and type:

node --version
npm --version

You should see version numbers like v18.17.0 and 9.6.7. If you see a number, Node.js is installed! ✅

Step 2

Set Up VS Code

VS Code is where you will write all your code. It's free and very popular.

1
Download VS Code

Go to code.visualstudio.com and download for your operating system.

2
Install these extensions

Inside VS Code, click the Extensions icon (looks like 4 squares) and install:

Prettier — auto formats your code to look neat
ESLint — highlights JavaScript errors
Live Server — preview HTML files instantly
MongoDB for VS Code — view your database
Step 3

Set Up MongoDB Atlas

Cloud database — no installation needed!

MongoDB Atlas is a free cloud database. Your data lives on MongoDB's servers, not your computer. You just need to create a free account and connect your app to it.

1
Create a free account

Go to mongodb.com/atlas and sign up for free. Choose the FREE shared cluster.

2
Create a database user

Go to Database Access → Add New User → set a username and password. Save these — you'll need them later.

3
Allow network access

Go to Network Access → Add IP Address → click "Allow Access from Anywhere" (for development only).

4
Get your connection string

Go to your cluster → Connect → Connect your application → copy the connection string. It looks like:

mongodb+srv://username:password@cluster0.xxxxx.mongodb.net/studentdb
Project Structure

Project Folder Structure

A good folder structure keeps your code organised. Here is the complete structure you will build in this course:

mern-student-app/ ← root folder (open this in VS Code) ├── backend/ ← all server code goes here │ ├── config/ │ │ └── db.js ← database connection │ ├── controllers/ │ │ └── studentController.js ← CRUD logic │ ├── models/ │ │ └── Student.js ← data shape/schema │ ├── routes/ │ │ └── studentRoutes.js ← URL routes │ ├── tests/ │ │ └── student.test.js ← automated tests │ ├── .env ← secret keys (never commit!) │ ├── package.json ← project settings │ └── server.js ← main server entry point │ ├── frontend/ ← React app (Member 3 builds) │ ├── .gitignore ← files Git should ignore └── README.md ← project description
Why split into folders?

Keeping config/, models/, controllers/, and routes/ separate means each file has one specific job. This makes it much easier to find and fix problems.

Version Control

Set Up Git & GitHub

Run these commands in the VS Code terminal (open with Ctrl + `) to initialise your project with Git:

git init
↳ Starts tracking your project folder with Git
git remote add origin https://github.com/your-username/mern-student-app.git
↳ Links your local folder to your GitHub repository
git add .
↳ Stages all files
git commit -m "initial project structure"
↳ Saves your first snapshot
git push origin main
↳ Uploads to GitHub
Important: .gitignore file

Create a .gitignore file and add node_modules/ and .env to it. This prevents uploading secret keys and large folders to GitHub.

.gitignore
node_modules/
.env
.DS_Store
Checklist

Verify Everything is Working

Before moving to Module 3, check that all of these are done:

Node.js installed — node --version shows a number
npm installed — npm --version shows a number
VS Code installed and extensions added
MongoDB Atlas account created and connection string saved
Project folder created with the correct structure
Git initialized and first commit pushed to GitHub
Something not working?

The most common issue is wrong Node.js version. Make sure you downloaded the LTS version (not "Current"). If node --version shows v16 or lower, re-download the LTS version.
