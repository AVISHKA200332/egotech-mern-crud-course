Install Node.js

1

Go to nodejs.org

Click the green LTS button — not "Current". LTS is stable and recommended for projects.

2

Run the installer

Open the downloaded file → Next → Accept License → Next → Install. On Windows, if asked about "Tools for Native Modules", check the box.

3

Verify — open a NEW terminal and run:

node --version

Expected: v20.x.x

npm --version

Expected: 10.x.x

If you see "node is not recognized", close the terminal completely and open a new one. If still failing, reinstall Node.js and ensure "Add to PATH" is checked during installation.

MongoDB Atlas — Free Cloud Database

Atlas hosts your database in the cloud. The M0 free tier is enough for this entire course.

1

Create a free account

Go to mongodb.com/atlas → Click "Try Free" → Sign up with email or Google account.

2

Create a cluster

Choose M0 Free Tier → Select your nearest region (e.g. Singapore for Sri Lanka) → Click "Create Cluster". Wait 1–2 minutes.

3

Create a database user

Database Access → Add New Database User → Username + strong password → Role: "Read and Write to any database". Save this password!

4

Allow all IP addresses

Network Access → Add IP Address → "Allow Access from Anywhere" (0.0.0.0/0) → Confirm. (Fine for development — restrict in production.)

5

Copy connection string

Cluster → Connect → "Connect your application" → Copy the URI. Replace <password> with your actual password.

Connection URI formatENV
mongodb+srv://<username>:<password>@cluster0.abc123.mongodb.net/studentDB?retryWrites=true&w=majority
Store this URI only in your .env file. Never paste it directly in JavaScript code. Never commit it to GitHub. Doing so exposes your database to the entire internet.

Complete Project Folder Structure

Create this clean layout before you start coding. Open your terminal in VS Code and run:

mkdir mern-student-app && cd mern-student-app
mkdir -p backend/config backend/controllers backend/models backend/routes backend/tests
mkdir -p frontend/src/components frontend/src/pages frontend/src/services

Recommended project layout

A neat separation between backend logic, frontend pages, and project config makes the app easier to grow.

MVC + React
Backend
  • dir config/ db.js
  • dir controllers/ studentController.js
  • dir models/ Student.js
  • dir routes/ studentRoutes.js
  • dir tests/ student.test.js
  • file .env private
  • file .env.example template
  • file package.json
  • file server.js
Frontend
  • dir src/
  • dir components/ Navbar, StudentCard
  • dir pages/ Add/Edit/List
  • dir services/ api.js
Project Root
  • root mern-student-app/
  • file .gitignore
  • file README.md
This follows the MVC pattern (Model → Student.js, View → React pages, Controller → studentController.js). Each file has exactly one responsibility — the foundation of professional, maintainable code.

Git & GitHub — Full Setup

Step 1 — Configure your Git identity (one time only)

git config --global user.name "Your Full Name"
git config --global user.email "your@email.com"

Step 2 — Initialize repository

git init

Run from inside mern-student-app/

Step 3 — Create .gitignore

.gitignoreTEXT
# Node dependencies — NEVER commit these (can be 100MB+)
node_modules/
npm-debug.log*

# Environment variables — NEVER commit (contains DB password)
.env
.env.local

# React build output
/frontend/build

# OS files
.DS_Store
Thumbs.db

# Logs
*.log

Step 4 — Create .env.example (safe to commit)

backend/.env.exampleENV
PORT=5000
MONGO_URI=mongodb+srv://<username>:<password>@cluster0.xxx.mongodb.net/studentDB

Step 5 — First commit and push to GitHub

git add .
git commit -m "init: project structure and configuration"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/mern-student-app.git

Create the repo on GitHub first (empty, no README)

git push -u origin main
Refresh your GitHub repository page — you should see your files! The green circle on each commit is your history being tracked. 🎉

Verify Your Complete Setup

  • node --version prints v18+ or v20+
  • npm --version prints 9+ or 10+
  • git --version prints a version number
  • VS Code open with 6 extensions installed
  • MongoDB Atlas cluster created, connection URI copied
  • backend/.env file created with PORT and MONGO_URI
  • Folder structure matches the tree shown above exactly
  • .gitignore includes node_modules/ and .env
  • First commit pushed to GitHub successfully
All boxes checked? You are fully set up and ready for Module 3 where we write our first real code!
