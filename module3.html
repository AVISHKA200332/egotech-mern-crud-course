Concept

What is Node.js?

Simple explanation

Normally, JavaScript only runs in browsers (like Chrome or Firefox). Node.js is a program that lets JavaScript run on your computer or server — outside of any browser. This means you can use JavaScript to build the backend (the server side) of a website.

  • Node.js is fast because it handles many tasks at the same time (non-blocking)
  • Node.js comes with npm — over 1 million free packages you can use
  • Node.js uses the same JavaScript you already know from the browser
Concept

What is Express.js?

Express = easy rules for your server

Express is a small library that sits on top of Node.js. Without Express, setting up a server requires a lot of complex code. With Express, you can set up a working server in about 10 lines. Think of Express as a manager that organises how your server handles incoming requests.

Setup

Setting Up With npm

Open your terminal, go to the backend/ folder, and run these commands:

cd backend
npm init -y
↳ Creates a package.json file — this tracks your project's settings and packages
npm install express mongoose dotenv cors
↳ Installs 4 packages we need: Express (server), Mongoose (database), dotenv (secrets), cors (allow frontend access)

↳ Dev tools: Nodemon (auto-restarts server on change), Jest + Supertest (testing)
What is a package?

A package is ready-made code written by other developers. Instead of writing everything from scratch, you install a package and use it. npm install downloads the package and saves it in the node_modules/ folder.

Code

Creating Your First Server

Create a file called server.js in the backend/ folder and add this code:

backend/server.js
// 1. Import the packages we installed
const express = require('express');
const cors = require('cors');
require('dotenv').config();

// 2. Create an Express app
const app = express();

// 3. Middleware — runs on every request
app.use(cors());              // allow React to talk to this server
app.use(express.json());     // understand JSON data in requests

// 4. A simple test route
app.get('/', (req, res) => {
  res.json({ message: 'Server is running!' });
});

// 5. Student routes (we build these in Module 5)
const studentRoutes = require('./routes/studentRoutes');
app.use('/api/students', studentRoutes);

// 6. Start the server on port 5000
const PORT = process.env.PORT || 5000;
app.listen(PORT, () => {
  console.log(`Server running on port ${PORT}`);
});

Now run your server:

node server.js

You should see: Server running on port 5000 ✅

Concept

What is Middleware?

Middleware = a security guard at the door

Every request that comes into your server goes through middleware first. Think of it like a security guard at a building entrance. The guard checks everyone before they're allowed in. In Express, middleware is a function that runs before your route handler — it can check things, modify things, or block requests.

example middleware
// This middleware runs on EVERY request
app.use((req, res, next) => {
  console.log(`${req.method} request to ${req.url}`);
  next(); // passes to next step (important!)
});

// express.json() is built-in middleware
// It reads the request body and converts JSON text to a JS object
app.use(express.json());
Routing

Defining Routes

A route tells Express: "when someone visits THIS URL with THIS HTTP method, run THIS code." Here are the routes we will build for our Student API:

MethodURLWhat it does
GET/api/studentsGet all students from the database
GET/api/students/:idGet one specific student by their ID
POST/api/studentsAdd a new student to the database
PUT/api/students/:idUpdate an existing student's info
DELETE/api/students/:idDelete a student from the database

Software Testing

Testing Your Server

We use Jest and Supertest to automatically test our routes. Here is a simple test:

backend/tests/server.test.js
const request = require('supertest');
const app = require('../server');

// Test 1: Root route should return 200
test('GET / returns server running message', async () => {
  const res = await request(app).get('/');
  expect(res.statusCode).toBe(200);
  expect(res.body.message).toBe('Server is running!');
});
npm test
↳ Runs all test files and shows pass/fail results
