What is MongoDB? — Beginner Explanation

MongoDB is a NoSQL database that stores data as documents (JSON-like objects) inside collections (similar to folders). Unlike SQL databases, there are no fixed columns — each document can have different fields.

?? SQL Term ? MongoDB Term
Database? Database
Table? Collection
Row? Document
Column? Field
Primary Key? _id
? Why MongoDB for MERN?
  • Data stored as JSON — same as React uses
  • No strict schema — flexible structure
  • Scales easily to millions of records
  • Free M0 tier on Atlas is enough for projects
  • JavaScript-friendly query API

What is Mongoose?

Mongoose is an ODM (Object Document Mapper). It acts as a bridge between Node.js and MongoDB — you define schemas and models in JavaScript, and Mongoose handles the translation to MongoDB commands.

Simple analogy: Mongoose is like a form template for your database. Instead of storing any random data, you define the exact shape first (schema) and Mongoose enforces it — rejecting invalid data before it reaches MongoDB.

Student Model — Full Mongoose Schema

backend/models/Student.jsJS
const mongoose = require('mongoose');

/**
 * Student Schema
 * Defines structure + validation for student documents
 */
const studentSchema = new mongoose.Schema(
  {
    name: {
      type: String,
      required: [true, 'Student name is required'],
      trim: true,
      minlength: [2,  'Name must be at least 2 characters'],
      maxlength: [50, 'Name cannot exceed 50 characters'],
    },

    email: {
      type: String,
      required: [true, 'Email address is required'],
      unique: true,      // no duplicate emails in DB
      lowercase: true,   // auto-converts to lowercase on save
      match: [
        /^\S+@\S+\.\S+$/,
        'Please provide a valid email address',
      ],
    },

    age: {
      type: Number,
      min: [1,   'Age must be at least 1'],
      max: [120, 'Age cannot exceed 120'],
    },

    course: {
      type: String,
      required: [true, 'Course is required'],
      enum: {
        values: ['IT', 'CS', 'Engineering', 'Business', 'Medicine', 'Other'],
        message: '{VALUE} is not a valid course option',
      },
    },
  },
  {
    timestamps: true,  // adds createdAt & updatedAt automatically
  }
);

const Student = mongoose.model('Student', studentSchema);
module.exports = Student;
mongoose.model('Student', studentSchema) creates a model named "Student". Mongoose automatically creates a MongoDB collection called students (lowercase + pluralized). You never create the collection manually.

Database Connection File

backend/config/db.jsJS
const mongoose = require('mongoose');

const connectDB = async () => {
  try {
    const conn = await mongoose.connect(process.env.MONGO_URI);
    console.log(`? MongoDB connected: ${conn.connection.host}`);
  } catch (error) {
    console.error(`? MongoDB error: ${error.message}`);
    process.exit(1); // stop app if DB fails — can't run without it
  }
};

module.exports = connectDB;

In server.js, call it at the top:

backend/server.js (add to top)JS
require('dotenv').config();
const connectDB = require('./config/db');
connectDB();  // call before anything else

Common Mongoose Queries

These are the 5 Mongoose methods you will use in the controller:

Mongoose Query ReferenceJS
// -- CREATE --------------------------------------
const student = await Student.create({ name, email, age, course });
// Returns the saved document including _id and timestamps

// -- READ ALL ------------------------------------
const all     = await Student.find().sort({ createdAt: -1 });
// Returns array of all documents, newest first

const itOnly  = await Student.find({ course: 'IT' });
// Returns only IT students (filter)

// -- READ ONE ------------------------------------
const one     = await Student.findById('64f2a1b3...');
// Returns one document by _id, or null if not found

// -- UPDATE --------------------------------------
const updated = await Student.findByIdAndUpdate(
  id,
  req.body,
  { new: true, runValidators: true }
  // new: true ? returns UPDATED doc, not the old one
  // runValidators ? applies schema validation on update
);

// -- DELETE --------------------------------------
const deleted = await Student.findByIdAndDelete(id);
// Returns the deleted document, or null if not found

Validation & Error Handling

Mongoose validates data before saving. Catch errors in your controller and send the right status code back:

Controller error handling patternJS
const createStudent = async (req, res) => {
  try {
    const student = await Student.create(req.body);
    res.status(201).json({ success: true, data: student });

  } catch (error) {
    // Missing required field or failed validation rule
    if (error.name === 'ValidationError') {
      const msgs = Object.values(error.errors).map(e => e.message);
      return res.status(400).json({ success: false, errors: msgs });
    }
    // Duplicate email (unique: true violated)
    if (error.code === 11000) {
      return res.status(409).json({
        success: false,
        message: 'A student with this email already exists',
      });
    }
    res.status(500).json({ success: false, message: error.message });
  }
};

Testing the Student Model

backend/tests/student.model.test.jsJS
const mongoose = require('mongoose');
const Student  = require('../models/Student');

beforeAll(async () => {
  await mongoose.connect(
    process.env.MONGO_URI_TEST || 'mongodb://localhost:27017/studentTest'
  );
});
afterEach (async () => { await Student.deleteMany({}); });
afterAll  (async () => { await mongoose.connection.close(); });

describe('Student Model', () => {

  it('creates a valid student', async () => {
    const s = await Student.create({
      name: 'Kaveesha Silva', email: 'k@test.com',
      age: 21, course: 'IT',
    });
    expect(s.name).toBe('Kaveesha Silva');
    expect(s._id).toBeDefined();
    expect(s.createdAt).toBeDefined();
  });

  it('fails when name is missing', async () => {
    let err;
    try { await Student.create({ email: 'x@t.com', course: 'IT' }); }
    catch (e) { err = e; }
    expect(err.name).toBe('ValidationError');
  });

  it('rejects duplicate email', async () => {
    const data = { name: 'A', email: 'dup@t.com', course: 'IT' };
    await Student.create(data);
    let err;
    try { await Student.create(data); } catch (e) { err = e; }
    expect(err.code).toBe(11000); // MongoDB duplicate key code
  });

});
